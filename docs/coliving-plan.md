# 코리빙 제안 구상

작성일 2026-10-06 · 상태: **구상 단계**. 운영사 접촉·계약 조건 등 정해진 것 없음. 코드·스키마에 아직 반영하지 않는다.

코리빙 운영사와 직접 제휴해, 요청에 중개사 매물과 함께 **코리빙 방도 제안**한다.

## 1. 왜 따로 다루나

코리빙은 단기 거주가 많아 공인중개사를 끼기 애매하고, 끼더라도 운영사가 고정 수수료를 주는 경우가 많다. 그래서 중개사를 거치지 않고 운영사와 직접 연결한다.

공급 성격도 중개사 매물과 다르다.

| | 중개사 매물 | 코리빙 |
| --- | --- | --- |
| 공급 단위 | 방 하나, 거래되면 끝 | 지점 → 방 타입(1인실 A/B…), 계속 같은 상품 |
| 가격 | 매물마다 협상 | 가격표 고정 (기간별 할인 정도) |
| 요청마다 할 일 | 중개사가 찾아서 등록 | 조건만 맞으면 자동으로 걸 수 있다 |
| 계약 | 임대차, 보통 2년 | 1개월~1년 단기, 서비스 이용계약인 경우도 있다 |
| 정산 | 중개수수료 (사용자 ↔ 중개사) | 운영사 → 집어줌 고정 수수료 |

지금 `Listing`은 층·준공연도·역 도보 등이 필수인 1회성 매물이다. 코리빙을 여기에 끼우기보다 **카탈로그로 따로 두고, 사용자 쪽(제안·찜·비교·문의)은 함께 쓴다.**

## 2. 구조 (안)

**데이터**
- `ColivingOperator` 운영사: 사업자 정보, 수수료 조건, 담당자 연락처
- `ColivingBranch` 지점: 주소, 좌표, 공용시설, 사진
- `ColivingRoomType` 방 타입: 월 이용료, 보증금, 최소 계약 기간, 포함 항목(관리비·인터넷·청소), 공실 여부
- `Proposal`은 공유: `listingId` 또는 `roomTypeId` 중 하나만 갖는다

**요청 입력**
- "코리빙도 받아볼게요" 선택
- **거주 예정 기간** (1~3개월 / 6개월 / 1년 이상). 지금은 입주일만 있고 기간이 없다. 코리빙 매칭의 핵심 조건이다

**매칭**
- 지점은 수백 곳 수준이라 지점 → 출근지 통근시간을 직접 잰다 (생활권 통계 불필요, 걸어서 15분 규칙도 그대로)
- 조건: 통근시간, 월 총비용 ≤ 예산, 입주일 공실, 최소 계약 기간 ≤ 거주 예정 기간
- 처음엔 운영자가 확인 후 보내는 반자동, 이후 자동 제안

**사용자 화면**
- 같은 제안 목록에 "코리빙" 배지로 섞어서 보여준다
- 비교는 **월 실부담**으로 맞춘다. 원룸 = 월세 + 관리비 + 보증금 기회비용(+ 가구 구입), 코리빙 = 이용료 + 포함 항목. 계산은 `packages/shared`
- 문의는 중개사 채팅 대신 **운영사 투어 예약**. 처음엔 운영사 상담 링크·전화, 이후 운영사 계정 채팅

**정산 추적**
- 문의 → 투어 → 계약 단계를 요청별로 기록, 운영사로 넘길 때 추천 코드를 붙인다

## 3. 단계

| 단계 | 내용 |
| --- | --- |
| 1. 검증 | 운영사 2~3곳. 운영 웹에서 지점·방 타입 직접 입력, 운영자가 수동 제안, 문의는 운영사 상담 링크. 입력에 "코리빙도 받기"·거주 기간만 추가 |
| 2. 자동화 | 자동 매칭, 월 실부담 비교, 계약 단계 추적 |
| 3. 운영사 연동 | 운영사 화면(공실·가격 직접 수정), 가능하면 API 연동 |

## 4. 먼저 확인할 것: 법적 구조

계약 성사마다 고정 수수료를 받는 구조는, 그 계약이 **임대차**라면 공인중개사가 아닌 집어줌이 중개보수를 받는 것으로 볼 여지가 있다 (공인중개사법상 무등록 중개). 운영사마다 계약 형태가 다르다.

- 운영사 계약이 임대차인지, 서비스 이용계약인지
- 수수료를 성사 보수가 아니라 광고·제휴 마케팅비(CPA, 고정 광고비)로 설계할 수 있는지

**법률 검토 후 정한다.**

## 5. 운영사 미팅 때 물어볼 것

- 계약 형태 (임대차 / 서비스 이용계약), 최소·최대 계약 기간
- 공실·가격 정보를 어떤 형태로 줄 수 있나 (엑셀 / 관리 화면 / API), 갱신 주기
- 수수료 기준 (계약 / 투어 / 문의)과 금액, 정산 방식
- 투어 예약 방법, 상담 담당자 연락 경로
- 사진·설명 사용 허락 범위

## 6. 미결정

- 제휴 운영사와 시작 시점
- 공실·가격 입력 주체 (집어줌 / 운영사)
- 문의 연결 방식 (외부 상담 링크 / 집어줌 채팅)
- 수수료 기준과 법적 구조
- "코리빙도 받기" 기본값 (켜짐 / 1인 가구만 노출)
